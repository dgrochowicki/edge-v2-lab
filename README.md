# EDGE v2 Lab

Experimental CS2 betting research project.

The goal is to test a new selection process on a clean sample of 10 bets before deciding whether the methodology has value.

This repository is separate from EDGE v1.

## Experiment

Target: 10 qualified bets.

Starting record: 0/10.

A PASS does not count toward the sample.

After 10 bets we review:
- ROI
- CLV
- probability calibration
- quality of pre-match reasoning
- recurring errors
- whether the process appears to identify value better than EDGE v1

Ten bets are not enough to prove profitability.
They are a first validation batch for the process.

## Core principle

Analysis first.
Price second.
Bet last.

We do not start with a bookmaker line and search for reasons to justify it.
